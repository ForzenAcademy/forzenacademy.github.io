# Figtree

Downloaded from the typeface author's official repository:
https://github.com/erikdkennedy/figtree

Original files:
- `fonts/webfonts/Figtree[wght].woff2`
- `fonts/webfonts/Figtree-Italic[wght].woff2`

The variable fonts cover weights 300–900. Their SIL Open Font License is
included as `OFL.txt`. These files ship with Hexed and require no external
font service at runtime.
